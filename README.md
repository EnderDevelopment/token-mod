# Token Mod

A Minecraft mod that adds special tokens with unique abilities.

## Features

- Adds special tokens with unique abilities to the game.
- Includes an Enderman Token and a Fire Token with distinct functionalities.

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.7 or later
- Fabric API

## Installation

1. Download the mod JAR file.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with the Fabric profile.

## Usage

- Collect tokens by exploring the world.
- Use tokens by right-clicking them in your inventory.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
